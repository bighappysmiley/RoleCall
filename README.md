# RoleCall

RoleCall is a hiring board by **BigHappySmiley**. Companies post jobs. People apply. Paid placement is always labeled.

Live site: https://rolecallats.netlify.app

There is **no demo board** and **no seed data**. The jobs list stays empty until real employers publish roles.

Operator setup (hosting, database, env keys) lives in [ENV.md](ENV.md).

## Stack

Next.js, Tailwind, shadcn/ui, Postgres, Drizzle, Better Auth, Stripe Checkout (test mode).
